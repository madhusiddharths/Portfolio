Overview

This project is a from-scratch, annotated implementation of the Vision Transformer (ViT) from the landmark paper "An Image is Worth 16×16 Words: Transformers for Image Recognition at Scale" (Dosovitskiy et al., ICLR 2021). Rather than calling a pre-built model, every component — patch embedding, the learnable [CLS] token, positional embeddings, the pre-norm Transformer encoder, and the classification head — is built in PyTorch and explained inline, in the spirit of Harvard NLP's "The Annotated Transformer."

On top of faithfully reproducing the architecture, the project goes further in three ways: we train a miniaturised ViT from scratch on CIFAR-10 to 72.9% test accuracy on a laptop GPU; we wrap the model in a single config object that scales unchanged from our 0.8M-parameter mini model all the way up to the paper's ViT-Base / Large / Huge (86M–632M parameters); and we implement a hybrid CNN-Transformer variant that swaps raw-pixel patches for ResNet feature maps. It was built as a three-person graduate course project (CS 577, Illinois Tech); my own focus was the training loop, experiment configuration, and hyperparameter tuning.

Background: Why Transformers for Vision

For a decade, Convolutional Neural Networks (AlexNet, VGG, ResNet) dominated computer vision because they bake in useful inductive biases: locality (convolutions act on local pixel neighbourhoods), translation equivariance (a feature is recognised wherever it appears), and hierarchical composition (edges → textures → parts → objects). Meanwhile, the Transformer's self-attention reshaped NLP by modelling relationships between all positions at once and scaling gracefully to billions of parameters.

ViT asks a deceptively simple question: can we apply a pure Transformer directly to images, with no convolutional priors? Its answer is to treat image patches as tokens — split the image into fixed-size patches, linearly embed each one, and feed the sequence to a standard Transformer encoder. The paper's central finding is about scale: trained on modest data a ViT underperforms ResNets, but pre-trained on enormous datasets (ImageNet-21k, or JFT-300M's 300M images) it reaches state-of-the-art — ViT-H/14 hits 88.55% on ImageNet using 4× less pre-training compute than the prior best. With enough data, learned attention beats hand-coded priors.

Architecture: Patches as Tokens

The model maps an image of shape (B, C, H, W) into a token sequence and runs it through the encoder: patch-embed to (B, N, D), prepend the [CLS] token to get (B, N+1, D), add positional embeddings, pass through L encoder layers, then project the final [CLS] representation to class logits.

1. Patch Embedding

The first step turns an image into a sequence. A neat implementation trick collapses two operations into one: a single Conv2d with kernel size = stride = patch size extracts each non-overlapping patch and projects it to the embedding dimension simultaneously. 

class PatchEmbedding(nn.Module):
    """(B, C, H, W) -> (B, N, D), where N = (H/P) * (W/P)."""
    def __init__(self, in_channels=3, embed_dim=768, patch_size=16):
        super().__init__()
        self.patch_size = patch_size
        # kernel = stride = patch_size: extract AND project in one op
        self.proj = nn.Conv2d(in_channels, embed_dim,
                              kernel_size=patch_size, stride=patch_size)

    def forward(self, x):
        x = self.proj(x)       # (B, D, H/P, W/P)
        x = x.flatten(2)       # (B, D, N)
        return x.transpose(1, 2)  # (B, N, D)

2. Class Token and Positional Embedding

Following BERT, a learnable [CLS] token is prepended to the patch sequence; its final state aggregates whole-image information for classification. Because attention is permutation-equivariant, we add learnable 1D positional embeddings to restore spatial order. Our implementation also supports bicubic interpolation of those embeddings, so a model trained at one resolution can be evaluated at another — exactly the mechanism the paper uses for fine-tuning at higher resolution.

The Transformer Encoder

The core is a standard Transformer encoder built in the pre-norm style: LayerNorm is applied before each sub-layer, multi-head self-attention and a GELU MLP each sit inside a residual connection, and a final LayerNorm closes the stack. Pre-norm keeps gradients well-behaved and makes deep stacks train stably. 

class TransformerEncoderBlock(nn.Module):
    """Pre-norm encoder block: LN -> MHSA -> residual, LN -> MLP -> residual."""
    def __init__(self, embed_dim, num_heads, mlp_ratio=4, dropout=0.0):
        super().__init__()
        self.ln1 = nn.LayerNorm(embed_dim)
        self.attn = nn.MultiheadAttention(embed_dim, num_heads,
                                          dropout=dropout, batch_first=True)
        self.ln2 = nn.LayerNorm(embed_dim)
        hidden = int(embed_dim * mlp_ratio)
        self.mlp = MLP(embed_dim, hidden, embed_dim, dropout)  # Linear-GELU-Linear

    def forward(self, x):
        x_norm = self.ln1(x)
        attn_out, _ = self.attn(x_norm, x_norm, x_norm, need_weights=False)
        x = x + attn_out                 # residual
        return x + self.mlp(self.ln2(x)) # pre-norm + residual

A Config-Driven Model Family

The whole network is parameterised by a single ViTConfig dataclass, so one VisionTransformer class scales across the entire ViT family by changing nothing but the config. The same code path that runs our tiny CIFAR model instantiates the paper's full-scale variants from Table 1.

The mini configuration deliberately shrinks the model to train on a laptop: 32×32 images, 4×4 patches (64 tokens), embedding dimension 128, 4 layers, and 4 heads — about 809K parameters. We also swap the paper's pre-training MLP head for a single linear layer: with only 10 CIFAR classes, the extra head capacity would invite overfitting, so a linear projection acts as a structural regulariser.

Going Beyond the Paper: A Hybrid CNN-Transformer

The ViT paper notes that patches don't have to come from raw pixels — they can come from a CNN's feature map. We implemented this hybrid variant: a truncated ResNet-18 backbone produces a spatial feature map, which is flattened into a token sequence and projected to the embedding dimension, then fed to the same encoder and head as the pure ViT. Because the rest of the model is modular, the swap is a single embedding module — positional embeddings, encoder, and head are reused unchanged. 

class HybridEmbed(nn.Module):
    """CNN feature map -> token sequence: (B, 3, H, W) -> (B, N, D)."""
    def __init__(self, backbone, embed_dim):
        super().__init__()
        self.backbone = backbone               # truncated ResNet-18
        with torch.no_grad():                  # infer feature-map shape once
            feat = backbone(torch.zeros(1, 3, 224, 224))
            self.num_patches = feat.shape[2] * feat.shape[3]
        self.proj = nn.Linear(feat.shape[1], embed_dim)

    def forward(self, x):
        x = self.backbone(x)                   # (B, C, H', W')
        x = x.flatten(2).transpose(1, 2)       # (B, N, C)
        return self.proj(x)                    # (B, N, D)

This reintroduces convolutional locality at the front of the network — giving the Transformer a head start on the spatial structure that pure ViT has to learn from scratch — and demonstrates the architecture's modularity rather than just reproducing a fixed recipe.

Training Setup

The CIFAR-10 training pipeline mirrors the paper's recipe, adapted for small-scale compute:

  • Optimiser: AdamW (weight decay 0.1) with a linear warmup then cosine decay learning-rate schedule, base LR 3e-4.
  • Regularisation: label smoothing (0.1), dropout in attention and MLP, and a single linear head.
  • Augmentation: RandomCrop(32, padding=4) and horizontal flips, with per-channel CIFAR normalisation.
  • Schedule & hardware: 20 epochs, batch size 64, a 90/10 train/val split, run on Apple MPS (with CUDA / CPU fallbacks and early-stopping checkpointing on best validation accuracy).

Results

Trained from scratch for 20 epochs, the 809K-parameter Mini-ViT reaches 72.91% test accuracy on CIFAR-10 (75.3% train / 72.5% validation at the final epoch). The loss curves converge smoothly and the train/val accuracy lines track each other closely, separating only late in training — a modest ~3-point generalisation gap rather than catastrophic overfitting, which is a respectable result for a pure Transformer with no pre-training on a dataset this small.

Why Mini-ViT Underperforms CNNs on CIFAR-10

A well-tuned CNN clears ~90%+ on CIFAR-10, so ~73% is below a convolutional baseline. That gap is the whole point of the experiment — it makes the paper's thesis tangible:

  • No inductive biases: the ViT must learn locality and translation equivariance that CNNs get for free, and 50K images isn't much to learn them from.
  • Small dataset: the paper showed Transformers need upward of 14M images to match CNNs; CIFAR-10 is three orders of magnitude smaller.
  • Low resolution: 32×32 images at 4×4 patches give just 64 tokens, limiting the long-range context self-attention is designed to exploit.
  • No pre-training: we train from scratch, whereas ViT's strength is transfer from large-scale pre-training — the single biggest lever we deliberately left on the table.

The takeaway isn't the absolute number — it's that a pure Transformer, implemented correctly from first principles, does learn to see, and that its ceiling on small data is exactly the limitation the paper predicts. The experiment reproduces the paper's conclusion, not just its code.

Discussion

Strengths of the ViT approach:

  • Scalability: attention scales with data and compute far better than convolutions.
  • Global receptive field: any patch can attend to any other from the very first layer.
  • Architectural simplicity: a standard Transformer encoder with no vision-specific operators.

Weaknesses and limitations:

  • Data hunger: needs large-scale pre-training to beat CNN baselines.
  • Quadratic attention cost: O(N²) in the number of patches caps practical resolution.
  • Resolution coupling: positional embeddings are tied to a resolution (hence the interpolation logic we implemented).

Where it goes next: data-efficient training recipes (DeiT), the hybrid CNN-Transformer we prototyped, self-supervised pre-training (MAE, BEiT), and hierarchical/windowed attention (Swin) all directly target the limitations this experiment surfaced.

Outcomes and Impact

  • Implemented the full Vision Transformer from scratch in PyTorch — patch embedding via a Conv2d trick, learnable [CLS] token, interpolatable positional embeddings, a pre-norm encoder, and the classification head — each annotated for clarity.
  • Designed a config-driven architecture where one model class spans Mini-ViT to ViT-Huge (0.8M–632M parameters) by changing only a dataclass.
  • Built a hybrid CNN-Transformer extension with a truncated ResNet-18 backbone, reusing the encoder and head unchanged.
  • Trained the Mini-ViT to 72.91% CIFAR-10 test accuracy from scratch on a laptop GPU with a tuned AdamW + warmup-cosine recipe, label smoothing, and augmentation — a modest ~3-point train/val gap.
  • Wrote up the implementation and analysis as a paper-style report, empirically reproducing the paper's core finding that ViT's small-data ceiling stems from its lack of convolutional inductive bias.

Conclusion

This project demonstrates that I can take a foundational deep-learning paper and rebuild it end-to-end — not just wiring up a library call, but implementing every block, scaling it with a clean config abstraction, extending it with a hybrid backbone, and then training and analysing it honestly. The Mini-ViT didn't break records on CIFAR-10, and it wasn't meant to: it makes the mechanics of patch embedding, positional encoding, and self-attention concrete, and it turns the paper's headline claim about data and inductive bias into a result you can see in the training curves. That blend of faithful implementation, architectural curiosity, and honest evaluation is exactly how I like to learn a hard idea deeply enough to build on it.
