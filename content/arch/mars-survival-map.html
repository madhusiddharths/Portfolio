Backend: one FastAPI service

server.py serves the viewer and every layer's map tiles, legends and point values. Each layer is one Python module (elevation.py, contours.py, firmness.py, ice.py, temperature.py, radiation.py) with the same two functions: a read_...(west, south, east, north, shape) that returns a NumPy array on the shared lon/lat grid, and a tile_png(level, row, col) that draws one map tile. routing.py reads those arrays for the ground between A and B, grades each 200 m cell, and runs the search with SciPy.

Frontend: no build step

The viewer is plain HTML, CSS and JavaScript on the ArcGIS Maps SDK for JavaScript: a rail of modes, one docked panel, the map and a status strip. The CTX imagery and the 3D terrain stream from Esri's Mars services; every other layer comes from our server as tiles. The route planner, the temperature panel and the immersive view are one script each.

Deployment

The app runs as a single Docker container on Google Cloud Run that scales to zero. The small grids ship inside the image. The 3.8 GB cloud-optimised elevation file sits in a Cloud Storage bucket, and GDAL fetches only the blocks a tile or a route needs.
