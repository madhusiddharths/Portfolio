Overview

SATURDAE (Structure And Technical User Rendered Digital Assistant Entity) is a floor-plan designer built for speed: place rooms and furniture with short commands and the plan draws itself, while the app refuses anything that would not fit in a real building. It is protected by Indian Patent Application No. 202341038832 A.

The patented design is driven by voice, with NLTK parsing spoken commands into an object, a position and an orientation. The code in the repository runs the same commands through a numbered menu, which made every placement rule testable without a microphone.

Inspiration

Professional drawing tools produce precise diagrams but take hours to learn. Someone who needs to show a layout in a meeting needs a sketch in minutes that is still to scale. SATURDAE trades the full toolbox for a fixed catalogue of standard-sized objects and a grid, so a plan is quick to make and accurate by default.

Approach

The plan lives on a 30×30 grid, drawn live with Python's turtle. Behind the drawing sits a 60×60 NumPy occupancy grid at half-foot resolution: every room and object marks the cells it covers, so the app can answer "does this fit?" before anything is drawn.

  • Placement: each object is first drawn as a green preview; only on confirmation is it drawn in black and written to the occupancy grid.
  • Collision checks: a placement is rejected if it overlaps another object, sits outside a room, or lands on a wall.
  • Room suggestions: when a new room would clash, the app proposes free positions above, below, left or right of the existing rooms.
  • Hallways: placing a door generates the hallway that connects it.
  • Editing: any room or object can be deleted, freeing its cells for the next placement.

Each concern is its own module (input loop, drawing, collision checks, suggestions, deletion), so a new object type is a drawing function plus a footprint, with no changes to the collision logic.

Conclusion

SATURDAE shows that a constrained tool can be faster than a powerful one: a fixed catalogue, a grid and a half-foot occupancy model are enough to produce plans that are quick to make and physically valid, with the app suggesting a fix instead of just refusing. The design was patented in India.
